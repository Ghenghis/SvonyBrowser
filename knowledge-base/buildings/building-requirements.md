# Evony Building Requirements Guide

## Overview

Buildings are the foundation of your city's development. Each building serves a specific purpose and has prerequisites for construction and upgrades.

## Building Priority

### Early Game (Keep 1-10)

1. Town Hall - Unlock features
2. Resource buildings - Economy
3. Barracks - Basic troops
4. Academy - Research
5. Walls - Defense

### Mid Game (Keep 11-20)

1. Town Hall - Continue upgrading
2. Academy - Advanced research
3. Military buildings - All troop types
4. Forge - Equipment
5. Hospital - Troop recovery

### Late Game (Keep 21-35)

1. Town Hall - Maximum level
2. All military buildings - Maximum training
3. Academy - All research
4. Walls - Maximum defense
5. Rally Spot - Maximum army size
