# Evony Hero Stats Guide

## Overview

Heroes in Evony are essential for leading armies, defending cities, and providing buffs. Each hero has base stats that can be enhanced through leveling, cultivation, and equipment.

## Base Stats

### Primary Attributes

| Attribute | Description | Effect |
|-----------|-------------|--------|
| **Politics** | Administrative ability | Increases resource production, construction speed |
| **Attack** | Offensive power | Increases troop attack damage |
| **Defense** | Defensive capability | Reduces damage taken by troops |
| **Leadership** | Command ability | Increases troop capacity and march speed |
| **Intelligence** | Strategic thinking | Increases trap damage, reduces enemy buffs |

### Stat Scaling

- Each level increases base stats by approximately 2-5%
- Cultivation can add up to 500 points per attribute
- Equipment provides percentage bonuses based on quality

Strong heroes available through various means:

- Baibars - Cavalry specialist
- Theodora - Politics and defense

Common heroes for early game:

- Basic generals with single specialties
- Good for resource gathering
- Can be used as sub-generals

## Hero Skills

### Skill Categories

1. **Active Skills** - Triggered during combat
2. **Passive Skills** - Always active bonuses
3. **Specialty Skills** - Unique to historic heroes

### Key Skills for Combat

| Skill Type | Effect | Priority |
|------------|--------|----------|
| Attack Buff | +X% troop attack | High |
| Defense Buff | +X% troop defense | High |
| HP Buff | +X% troop HP | Medium |
| March Speed | +X% march speed | Medium |
| Enemy Debuff | -X% enemy stats | High |

## Cultivation

### Cultivation Tiers

| Tier | Max Points | Cost |
|------|------------|------|
| Green | 100 | Low |
| Blue | 200 | Medium |
| Purple | 300 | High |
| Orange | 400 | Very High |
| Gold | 500 | Extreme |

### Optimal Cultivation

- **Attack Heroes**: Focus on Attack > Leadership > Defense
- **Defense Heroes**: Focus on Defense > Politics > Leadership
- **Gathering Heroes**: Focus on Politics > Leadership > Attack

## Equipment

### Equipment Slots

1. Weapon - Primary attack boost
2. Armor - Primary defense boost
3. Helmet - HP and defense
4. Boots - March speed
5. Accessory 1 - Various stats
6. Accessory 2 - Various stats

### Equipment Quality

| Quality | Color | Stat Bonus |
|---------|-------|------------|
| Common | White | +5-10% |
| Uncommon | Green | +10-20% |
| Rare | Blue | +20-35% |
| Epic | Purple | +35-50% |
| Legendary | Orange | +50-75% |
| Mythic | Gold | +75-100% |

## Hero Pairing

### Main + Assistant System

- Main hero provides primary skills
- Assistant hero provides stat bonuses (50% of their stats)
- Choose assistants with complementary skills

### Recommended Pairings

| Main Hero | Best Assistant | Reason |
|-----------|----------------|--------|
| Hannibal | Genghis Khan | Double cavalry buffs |
| Scipio | Charles Martel | Maximum defense |
| Alexander | Any specialist | Versatile base |

## Leveling Guide

### Experience Sources

1. Monster hunting - Primary source
2. Boss rallies - High XP
3. Experience items - Direct application
4. Subordinate cities - Passive XP

### Level Milestones

| Level | Unlock |
|-------|--------|
| 20 | Second skill slot |
| 25 | Third skill slot |
| 30 | Fourth skill slot |
| 35 | Specialty enhancement |
| 40 | Maximum skill slots |

## Star Levels

### Star Upgrade Benefits

- Each star increases base stats by 10%
- Unlocks additional skill slots
- Maximum 10 stars for historic heroes

### Star Upgrade Materials

- Hero medals (specific to each hero)
- Gold
- Runestones (for higher stars)
